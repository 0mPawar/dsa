## 🚀 How to Run

Make sure a C++ compiler is installed on your system.

Using `g++`:

```bash
g++ practicals/practical-01-array-operations.cpp -o practical
./practical
```

On Windows:

```bash
g++ practicals/practical-01-array-operations.cpp -o practical.exe
practical.exe
```

The exact compilation command may vary depending on the compiler and operating system.

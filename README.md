## 📂 CCE Projects

This repository includes the following Course Continuous Evaluation projects:

### CCE-2 Part 1: Music Playlist Manager

A menu-driven C++ application that implements a music playlist using a **Doubly Linked List**.

Key operations include:

- Adding and deleting songs
- Forward and reverse playlist traversal
- Playing the current, next, and previous songs
- Playing the complete playlist

### CCE-2 Part 2: Stack and Queue Implementations

Implementation of stacks and queues using two different approaches:

- Stack using Array
- Queue using Array
- Stack using Linked List
- Queue using Linked List

The programs demonstrate fundamental stack and queue operations, including insertion, deletion, and traversal.

### CCE-3: Smart Road Network & Route Finder

A menu-driven C++ application that represents a road network using a **Weighted Undirected Graph**.

Key features include:

- Adding locations and roads
- Displaying the road network using an adjacency matrix
- Finding the shortest route using Dijkstra's algorithm
- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Searching locations
- Sorting connected roads by distance
- Deleting roads

Each CCE project has its own README containing its overview, objectives, features, data structures, algorithms, execution instructions, and conclusion.

## 🚀 How to Run

Make sure a C++ compiler, such as **G++**, is installed on your system.

Navigate to the directory containing the required `.cpp` file and compile it.

**Using G++ on Linux:**

```bash
g++ filename.cpp -o program
./program
```

**Using G++ on Windows:**

```bash
g++ filename.cpp -o program.exe
program.exe
```

For example, to compile a practical:

```bash
g++ practicals/filename.cpp -o practical
```

The exact compilation command may vary depending on the compiler and operating system.

# DSA Practicals

A collection of **Data Structures and Algorithms (DSA)** practical programs implemented in **C++** as part of my B.Tech/BE coursework.

This directory contains practical implementations covering object-oriented programming concepts, searching and sorting algorithms, linked lists, stacks, queues, expression evaluation, and graph traversal.

## 🧠 Topics Covered

The practical programs demonstrate the following concepts:

- **Object-Oriented Programming:** Classes, Objects, Constructors and Operator Overloading.
- **Searching:** Linear Search and Binary Search.
- **Sorting:** Bubble Sort.
- **Linked Lists:** Singly Linked List and Doubly Linked List.
- **Stacks:** Stack implementation using Arrays and Linked Lists.
- **Queues:** Queue implementation using Arrays and Linked Lists.
- **Expression Evaluation:** Postfix Expression Evaluation using Stack.
- **Graphs:** Graph Representation using Adjacency Matrix and Depth-First Search.

## 🚀 How to Run

Make sure a C++ compiler such as **G++** is installed on your system.

**Step 1:** Open a terminal in the `practicals/` directory.

**Step 2:** Compile the required C++ file.

```bash
g++ practical-01-operator-overloading.cpp -o practical
```

**Step 3:** Execute the compiled program.

On Linux:

```bash
./practical
```

On Windows:

```bash
practical.exe
```

Replace the filename with the practical program you want to execute.

## ⚙️ Important Notes

- Each `.cpp` file is an independent program and should be compiled separately.
- Binary Search requires the input array to be sorted.
- The array-based Stack and Queue implementations use fixed-size arrays.
- The Postfix Expression program supports single-digit operands and the operators implemented in its source code.
- The DFS program starts traversal from vertex `0` and uses an adjacency matrix.
- Input constraints and supported operations depend on the individual implementation.
